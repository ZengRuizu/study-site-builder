# Instructions for AI agents

This repository is a skill: it turns course slides into an interactive bilingual single-file study website.
Read `SKILL.md` and follow it exactly. Then read `references/authoring.md`, `references/pedagogy.md`, `references/quality.md` and `references/design.md` (storage, save codes, versions).
`examples/demo-sorting/` (built: `docs/index.html`) is the minimum quality bar; `templates/course/` is the starting point for a new course; `addons/` holds optional widget packs.
Build with `scripts/build.py`, verify with `scripts/verify.py` (must print `RESULT: PASS`).
Do not commit or push to this repository. Never add course slides, past papers or other copyrighted course material to it — generated sites for real courses stay in the student's own folders.
